# Notebooks

The maintained pipeline is in `src/energy_forecasting/` and runs from `main.py`.
Use this folder for optional exploratory notebooks; keep notebooks focused on
questions that are not already answered by the saved charts and reports.

Suggested first notebook: inspect `data/raw/synthetic_energy.csv`, compare
weekday and weekend profiles, and explain why the first 168 hours are excluded
when building weekly-lag features.
